**Découvertes Claude Code** :
- La mémoire auto est locale à la machine : elle n'existe ni dans le cloud ni sur un autre poste. Le dépôt devient la mémoire du projet.
- Un `@chemin` dans `CLAUDE.md` charge le fichier à chaque session ; un chemin entre backticks reste un simple pointeur, lu au besoin.
- Une règle de `.claude/rules/` avec `paths` ne se charge qu'à la lecture ou l'écriture d'un fichier correspondant ; les fils de projet cloud l'ignorent.
- Seule la forme `.claude/skills/<nom>/SKILL.md` est documentée pour les skills : pas de dossiers de regroupement, d'où le préfixe `vendor-`.
- Remote Control (`/remote-control` ou `/rc`, y compris dans l'extension VS Code) permet de suivre et d'approuver une session depuis le téléphone ; la fenêtre doit rester ouverte et le poste éveillé.
- Une permission en lecture comme `git log *` laisse passer `--output=` : une règle d'autorisation n'est jamais aussi étroite qu'elle en a l'air.
