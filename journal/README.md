# Journal

Repère d'apprentissage Claude Code et historique du projet : ce qui a été fait, appris et décidé, session par session.

## Nommage

Un fichier par session : `AAAA-MM-JJ-session-N.md`, avec la date de la session et son numéro.

## Gabarit d'une entrée

```markdown
## Session N, JJ/MM/AAAA

**Objectif** : ce que la session devait accomplir.

**Fait** : ce qui a été réalisé.

**Commits** : les commits de la session, tirés de `git log`.

**Découvertes Claude Code** : ce qui a été appris sur l'outil.

**Décisions** : les choix tranchés.

**Suite** : ce qui vient après.
```

Les sessions 1 à 3 sont antérieures à ce gabarit et restent telles qu'elles ont été écrites.
